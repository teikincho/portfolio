WESHINE · ANNIVERSARY

闪萌周年庆 IP 集合

以周年庆为节点汇集闪趣科技旗下多组角色 IP，通过集体庆祝画面、周年庆插画和 3D 场景，让不同角色在同一主题下形成可识别的品牌内容资产。

闪趣科技 · 闪萌周年庆视觉多 IP 集合2D / 3D 延展
01 / IP Collection

让各具个性的角色，在周年庆里站到同一个舞台

主集合画面以闪萌角色群像为中心，兼容拟人角色、动物角色与软萌形象。通过统一的线条、轮廓和庆祝道具，建立跨 IP 的整体氛围。

群像画面作为周年庆内容的核心集合视觉，可用于专题页首屏、活动海报和社交传播素材。

02 / 6th Anniversary

用一座 3D 内容工厂，承接六周年的创作能量

以明亮的黄绿色作为周年庆主色，结合数字“6”、生产线、透明材质与角色窗口，构建兼具科技感和趣味感的三维庆祝场景。

  • 数字“6”成为周年识别锚点
  • 生产线隐喻持续产出的内容与 IP
  • 透明材质与柔和色彩平衡科技感
  • 小型角色嵌入装置，维持品牌温度
03 / Visual Extensions

同一周年主题，延展为不同媒介的角色叙事

2D 插画以更强的叙事性和高饱和色彩承接社交内容；三维场景则强调装置感和周年数字，使两种表达共享“庆祝、连接、创作”的主题。

2D 周年庆插画将角色、手机互动、派对帽和太空场景拼接为跨次元的庆祝叙事。
3D 周年庆场景以数字、生产线和内容装置延展“闪萌六周年”的视觉主题。
WESHINE IP FAMILY

从单个角色到 IP 家族

周年庆集合视觉沉淀了公司多个角色的共同表达方式：亲和的情绪、清晰的轮廓、丰富的互动道具，以及适合在多种内容载体上扩展的画面组织。
