圣诞肌密行动
失踪的资料

美丽修行 × HEY:REALH5 UI / UX活动资源位2023

围绕“失踪的资料”构建节日主题互动活动。用户通过验证身份、完成任务、收集五张线索卡并合成情报，进入抽奖与证书分享；同时通过好友助力扩大活动参与和传播。

活动主线与交互步骤

01 / 任务收集到奖励分享

将复杂活动拆分为连续的目标和状态反馈：身份验证开启任务，情报值兑换抽卡机会，五类线索卡集齐后合成情报，最终完成抽奖并生成专属证书。

进入首页→阅读召集令→验证身份→获取情报值→抽取线索卡→合成情报→抽奖与证书→分享 / 好友助力

UI 细节与状态思考

02 / 卡牌系统

用同一张基础卡牌建立收集规则，再通过灰阶和金色区分未获得、已获得与合成完成状态；文字卡面帮助用户快速理解每张线索的类别。

状态可感知

灰阶卡牌表示未获得，金色卡牌表示已收集，让进度无需额外说明即可被识别。

任务与奖励连通

以情报值作为抽卡成本，任务清单、线索卡和奖励之间形成明确的激励循环。

关键节点强化

抽卡、合成和抽奖均采用遮罩与大尺寸视觉反馈，强调完成任务后的仪式感。

开屏、Banner 与活动资源位

03 / 多触点传播

将活动主视觉适配到开屏、信息流、热门入口、站内弹窗、话题活动与分享图，在不同尺寸中保留线索板、雪景和卡牌等核心识别元素。

项目页面按用户进入、任务收集、奖励反馈和传播延展的顺序整理，集中呈现 H5 活动的界面与资源位设计。
