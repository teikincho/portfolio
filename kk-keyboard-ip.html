KK KEYBOARD · IP DESIGN

KK键盘IP 角色设计

为 KK键盘设计一位具有屏幕感和陪伴感的机器人角色。从草图中的方盒轮廓出发，逐步建立圆角显示屏、发光眼睛与双侧耳部的核心辨识特征，并沉淀成可复用的角色规范。

闪趣科技 · KK键盘IP 角色设计视觉规范多视图输出
01 / Design Process

从一个会回应的屏幕，构思陪伴型机器人角色

设计过程先确定亲和的方形主体和电子屏幕，再以发光眼睛、微笑嘴角和圆形耳部赋予角色表情；随后通过不同视图与图形规范确保角色能稳定地延展到产品各处。

01 / IDEA提炼“屏幕”和“回应”两个核心联想
02 / SKETCH用简洁体块测试机器人的表情与结构
03 / REFINEMENT确定圆角外框、屏幕层级与耳部比例
04 / SYSTEM输出多视图、线稿与不同呈现规范
01 · 概念线稿以对话气泡、心形与小星星表现角色的沟通、陪伴和轻快感；立方体轮廓为后续结构建立基础。
02 · 造型初稿把屏幕感转化为多层圆角面板，以蓝色边框、深色屏幕和发光眼睛建立高识别度的正脸。
02 / Character Views

用正、侧、背视图约束角色结构

多视图明确主体厚度、耳部的位置和屏幕面板的层级关系，让角色在插画、动效和产品界面中的角度变化保持一致。

正视图集中呈现屏幕表情与对称耳部。
侧视图标注角色体块厚度与侧面结构。
后视图补齐背面轮廓，形成完整三视图。
03 / Visual Details

色彩、轮廓和线稿共同维护角色识别

通过成品正视图、单色稿、描边稿与线稿，规定不同场景下应保留的角色特征，使图标尺寸缩小或单色输出时仍然清晰可辨。

成品造型

深蓝屏幕与青色表情形成视觉焦点，白色外壳保持轻盈。

单色稿

抽取大轮廓与表情特征，用于受限的单色应用场景。

描边与线稿

以轮廓和内部线条保留结构层级，支撑印刷与简化展示。

04 / IP System

把角色从单张形象变成可交付的设计资产

角色规范覆盖结构视图、基础色彩、单色表现和描边样式。它让后续页面、图标、物料或动效制作可以在同一套角色语言上持续扩展。
